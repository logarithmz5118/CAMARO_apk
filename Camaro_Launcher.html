🚗 내 차 안드로이드 올인원에 바로 설치하는 2가지 방법

복잡한 코딩 없이 아래 두 가지 방법 중 편한 것을 골라 그대로 따라 하시면 됩니다.

방법 A · 가장 쉬움 (1분 컷 추천!)

APK 변환 없이 HTML 파일 그대로 홈 런처로 쓰기

  1. 상단 바의 [📥 HTML 런처 다운] 버튼을 눌러 Camaro_Launcher.html 파일을 받습니다.
  2. 받은 파일을 USB나 네이버 마이박스/구글 드라이브를 통해 차량 올인원의 Download 폴더에 넣습니다.
  3. 올인원 플레이스토어에서 무료 앱 Fully Kiosk Browser (또는 WebView Kiosk)를 설치합니다.
  4. 앱 실행 후 Start URL 칸에 아래 주소를 입력합니다:
    file:///sdcard/Download/Camaro_Launcher.html
  5. 설정에서 전체화면(Fullscreen)과 기본 홈 런처로 사용(Set as Launcher)을 켜면 시동을 걸자마자 카마로 런처가 바로 실행됩니다!
방법 B · 진짜 .APK 설치 파일 만들기 (무료/무설치)

PC 프로그램 설치 없이 GitHub에서 자동으로 APK 굽기

  1. 상단 바의 [📦 APK 제작용 ZIP 다운] 버튼을 눌러 Camaro_Android_APK_Project.zip을 다운받아 압축을 풉니다.
  2. GitHub.com에 무료 가입/로그인 후 New Repository(새 저장소)를 하나 만듭니다.
  3. 압축을 푼 폴더 안의 파일들을 마우스로 끌어다 GitHub 화면에 전부 업로드하고 Commit changes(저장)를 누릅니다.
  4. GitHub 상단 메뉴의 [Actions] 탭을 누르면 자동으로 APK 생성이 시작되며, 약 2분 뒤 완료되면 하단 Artifacts에서 완성된 Camaro-RS-Launcher-APK (app-debug.apk)를 다운받아 올인원에 바로 설치하시면 됩니다!
